# GitHub User Finder

**Автор:** Матушайтис Даниил
**Дата выполнение:** Май 2026

## Описание
GitHub User Finder - Графическое приложение для поиска пользователей GitHub через официальное API.


## Возможности
- Искать пользователей по логину или имени.
- Просматривать результаты (логин, ID, ссылка на профиль).
- Добавлять пользователей в избранное.
- Удалять из избранного.
- Сохранять избранных в файл `favorites.json` (автоматическая загрузка при запуске).

### Тестирование:
- **Поиск:** Поле поиска не должно быть пустым.
- **Добавление в избранное:** Для добавления пользователя в "избранное", его надо выбрать. 

## Как используется GitHub API
Приложение отправляет GET-запрос к эндпоинту: https://api.github.com/search/users?q={query}
где `{query}` — введённая пользователем строка.
Ответ содержит JSON с полем `items` — массив найденных пользователей.
Из каждого пользователя извлекаются: `login`, `id`, `html_url`.
Документация: [GitHub Search API](https://docs.github.com/ru/rest/search/search?apiVersion=2022-11-28#search-users)

## Требования
- Python 3.6+
- Библиотеки: `tkinter`, `requests`, `json`, `os`, `threading` (все встроенные, кроме `requests`).
